# 后端架构师 / AI 工程化专家 — 岗位说明书（虚构示例）

> 虚构示例：本 JD 中的公司「星澜科技」、团队、业务场景均为虚构，仅供演示 skill 的 JD 解析步骤（Step 2）使用。

## 公司与团队（虚构）

**星澜科技**（虚构）是一家面向电商与内容平台的 SaaS 服务商，日均承载约 8000 万次 API 调用。
研发中心下设「智能平台组」，负责公司内部的 AI 工程化底座与智能体应用落地。

## 工作职责

### 岗位定位
面向企业级业务系统和智能体应用，借助 AI 原生开发工具与技术，负责端到端系统架构设计、软件开发与维护。

### 核心职责

1. **核心系统架构设计与研发**
   主导企业级应用系统后端整体架构设计、核心服务设计、迭代演进与性能 / 稳定性优化，构建高可用、可扩展、易维护的技术底座，支撑业务快速规模化落地。

2. **AI 智能体全链路工程化落地**
   负责 AI 智能体从链路设计、服务编排、接口封装、模型调用、调度优化到异常治理全流程落地，打通技术链路，保障 AI 能力高效、稳定、低成本对接业务系统。

3. **AI 技术体系建设与业务融合**
   采用 AI 开发工具，运用 Spec Driven 等 AI 原生软件开发方式，赋能软件开发过程，提升软件开发效率和质量。

4. **技术团队与研发效能提升**
   主导技术方案评审、核心代码规范、技术沉淀与团队能力建设，推动 AI + 后端研发流程标准化。

## 任职资格

### 任职要求

1. **学历背景**
   本科及以上学历，计算机、软件工程、人工智能等相关专业优先。

2. **工作经验**
   - 5 年及以上企业级应用系统或互联网软件系统后端架构 / 核心研发经验
   - 具备高并发、分布式系统架构设计与落地经验
   - 1 年及以上 AI 工程化落地实践经验

3. **核心技术能力**

   (1) **架构能力**
   具备端到端系统架构设计能力，精通分布式 / 微服务架构理念，能独立完成从网关入口、服务编排、链路调度到存储层的整体方案设计。

   (2) **全栈技术理解**
   熟悉主流后端技术体系，不局限开发语言，精通服务开发、中间件（Redis / MQ / MySQL 等）使用与调优。

   (3) **AI 工程化核心能力**
   深入理解 AI 智能体工作机制、大模型调用链路、Prompt 工程、RAG、函数调用等技术。

   (4) **问题解决能力**
   具备复杂技术问题定位、架构重构、性能瓶颈突破能力。

4. **加分项**
   - 主导过 AI 智能体、大模型应用从 0 到 1 落地全流程经验
   - 有开源贡献、技术架构分享沉淀
   - 有企业数智化转型、AI + 业务深度融合项目经验
