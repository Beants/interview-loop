# 软性素质种子词典 — 归一化辅助（参考）

> 性质：本词典**不是固定要求清单**，只做两件事——(a) 同义词归一化（把 JD 里「沟通能力 / 表达能力 / 跨部门协作」归一到「沟通协作」），(b) 给每个标签一个标准定义 + 考察提示。**最终要求清单由 JD 决定**，词典只让不同 JD 的标签可对齐。JD 没要求的词典项**不**进清单。

> **边界（硬约束）**：本词典**不包含任何心理测评问卷 / 量表 / 测评体系**。它只是「分类法 + 同义词 + 定义」，不做任何「测量 / 打分 / 常模 / 百分位」。引入的全部来源都是职业分类法或公开报告，不是测评工具。

## 与现有元能力五项的映射（不另起炉灶）

每个标签都映射回 skill 现有的元能力五项（自知力 / 态度-可管理性 / 可引导性 / 沟通 / 诚实度），保证软性素质对比与现有评测框架**同源、可叠加**，而不是另起一套独立分数：

| 词典标签（归一化后） | 主映射元能力 | 辅映射元能力 |
|----------------------|-------------|-------------|
| 沟通协作 | 沟通 | — |
| 责任心 / Ownership | 态度 / 可管理性 | — |
| 主动性 / 自驱 | 态度 / 可管理性 | 沟通 |
| 学习能力 | 可引导性 | 自知力 |
| 抗压与坚韧性 | 态度 / 可管理性 | 可引导性 |
| 诚实度 / 诚信 | 诚实度 | — |
| 自知力 / 自我认知 | 自知力 | 诚实度 |
| 可引导性 / 可管理性 | 可引导性 | 态度 / 可管理性 |
| 注重细节 / 严谨 | 态度 / 可管理性 | — |
| 创新 / 分析思维 | 可引导性 | 自知力 |

> 映射关系是「软性素质标签 → 元能力」的归口，不是 1:1。对比表的「综合判定」最终落在元能力反应上（沿用 SKILL.md 评价哲学原则二：「不会」看元能力反应）。

## 词典正文（~10 个归一化标签）

### 1. 沟通协作（Communication & Collaboration）
- **定义**：能清晰表达、跨角色 / 跨部门对齐信息，把复杂讲简单，让对方听得懂、对得上。
- **同义词**（归一化用）：沟通能力 / 表达能力 / 跨部门协作 / 团队沟通 / 汇报能力 / 推动协作 / 对齐
- **O*NET 映射**：Cooperation、Social Orientation
- **映射到现有元能力**：沟通（主）
- **考察提示**：能否把复杂讲简单（沟通四层 L1-L4）；答非所问 / 越解释越乱 = 减分信号；跨部门项目里是「对齐方」还是「各做各的」。

### 2. 责任心 / Ownership（Responsibility & Ownership）
- **定义**：对结果负责，主动 owner 端到端，不甩锅；出了问题先想怎么补，而不是先撇清。
- **同义词**：担当 / 主人翁意识 / 负责任 / 结果导向 / 主导 / 端到端负责 / 兜底
- **O*NET 映射**：Achievement Orientation、Persistence
- **映射到现有元能力**：态度 / 可管理性（主）
- **考察提示**：项目里是「主导」还是「参与」；线上出事是「我来兜底」还是「这不是我的模块」；被拆穿后是否狡辩 / 甩锅。

### 3. 主动性 / 自驱（Initiative / Proactivity）
- **定义**：不等派活就动手，主动找问题、提方案、推标准化；对自己有要求，不止步于「完成交代的事」。
- **同义词**：自驱 / 进取心 / 主动 / 积极主动 / 自我驱动 / 推动力
- **O*NET 映射**：Initiative、Achievement Orientation
- **映射到现有元能力**：态度 / 可管理性（主）、沟通（辅）
- **考察提示**：是「等需求」还是「主动发现并推动」；有没有把个人经验沉淀成团队标准 / 规范；推动遇到阻力时是放弃还是想办法。

### 4. 学习能力（Learning Ability / Adaptability）
- **定义**：快速理解新概念并迁移到自己的场景；对未知保持好奇，遇到不会的愿意学而不是绕开。
- **同义词**：学习意愿 / 快速学习 / 持续学习 / 技术好奇心 / 迁移能力 / 举一反三
- **O*NET 映射**：Adaptability、Innovation
- **映射到现有元能力**：可引导性（主）、自知力（辅）
- **考察提示**：给提示 / 类比后能不能跟上；最近在学什么、为什么学；能不能把 A 领域的方法迁移到 B（如 RL → RLHF）。

### 5. 抗压与坚韧性（Stress Tolerance & Persistence）
- **定义**：在高并发 / 线上故障 / 紧急交付等压力场景下仍能稳定输出、不崩；遇阻反复试，不轻易放弃。
- **同义词**：抗压 / 韧性 / 情绪稳定 / 压力下表现 / 坚持 / 死磕
- **O*NET 映射**：Stress Tolerance、Persistence、Self-Control
- **映射到现有元能力**：态度 / 可管理性（主）、可引导性（辅）
- **考察提示**：有没有线上故障 / 紧急救火的真实经历（引原文）；被连续追问 / 被指出错误时情绪是否稳定；困难任务是坚持还是退缩。

### 6. 诚实度 / 诚信（Integrity）
- **定义**：实事求是，会就是会、不会就是不会；不编造数据、不贪功、不甩锅。**多数岗位默认为红线。**
- **同义词**：诚信 / 诚实 / 实事求是 / 不造假 / 如实陈述
- **O*NET 映射**：Integrity
- **映射到现有元能力**：诚实度（主）
- **考察提示**：量化指标有无 baseline（无 baseline = 风险信号）；角色是「我负责」还是「参与了」；被拆穿后是承认还是狡辩 / 编造。实习生岗一票否决。

### 7. 自知力 / 自我认知（Self-Awareness）
- **定义**：清楚自己会什么、不会什么，主动暴露短板而非包装；能反思项目里的不足。
- **同义词**：自我认知 / 自我反思 / 认识短板 / 虚心 / 有自知之明
- **O*NET 映射**：Self-Control（部分）；WEF：Self-awareness
- **映射到现有元能力**：自知力（主）、诚实度（辅）
- **考察提示**：会不会主动说「这块我没做过 / 不熟」；问「项目最大短板」能不能答出真问题；技术术语是堆砌还是能讲透。

### 8. 可引导性 / 可管理性（Coachability & Manageability）
- **定义**：给提示 / 方向后能跟上、能调整；听得进反馈，不犟嘴、不拒绝思考；好协作、好培养。
- **同义词**：可培养 / 听劝 / 接受反馈 / 可引导 / 好管理 / 配合度高
- **O*NET 映射**：Cooperation、Self-Control
- **映射到现有元能力**：可引导性（主）、态度 / 可管理性（辅）
- **考察提示**：给提示后的反应（跟上 / 放弃 / 犟）；被指出错误是接受并调整还是辩解；外包 / 初级岗此项权重 40-50%。

### 9. 注重细节 / 严谨（Detail Orientation / Conscientiousness）
- **定义**：对正确性敏感，有质量意识；边界条件、异常路径、数据校验都想得到、处理得了。
- **同义词**：严谨 / 细致 / 认真 / 质量意识 / 一丝不苟 / 靠谱
- **O*NET 映射**：Attention to Detail、Dependability
- **映射到现有元能力**：态度 / 可管理性（主）
- **考察提示**：量化指标有没有标定 / 校验；异常 / 边界场景有没有考虑（如 RAG 后校验、限流降级）；交付物是「能跑」还是「经得起 review」。

### 10. 创新 / 分析思维（Innovation & Analytical Thinking）
- **定义**：不照搬，能针对新问题做权衡与原创；能把复杂问题拆解、用数据 / 逻辑支撑决策。
- **同义词**：创新 / 创造性 / 分析思维 / 批判性思维 / 独立思考 / 权衡能力
- **O*NET 映射**：Innovation、Analytical Thinking
- **映射到现有元能力**：可引导性（主）、自知力（辅）
- **考察提示**：技术选型能不能说清「为什么选 A 不选 B」；有没有自研 / 改进而非纯调包；评估方法是不是科学的（有对照、有反思）。

## 使用须知（防范围蔓延）

1. **JD 是唯一要求标尺**：本词典只负责把 JD 措辞归一化到标签，**不**决定要评哪些项。要求清单来自 JD（显式直接引用 / 隐式注明推断依据），JD 没要求的词典项**不**进清单。
2. **粒度可调**：首版按国内 HR 常见术语归并到 ~10 项，避免粒度过细。团队可按习惯增删标签，但增删后仍须保持「只归一化、不当固定要求清单」。
3. **不替代知识层评测**：软性素质标签映射到元能力层，知识层（AI 工程化 / 架构 / 量化等）评分**不**因软性素质对比而变化。
4. **零测评**：本词典**不是**任何心理测评工具，不产生分数 / 常模 / 百分位；只做结构化抽取与对比。
