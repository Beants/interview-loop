# data/ — 私有面试数据落点

这个目录是本仓库**唯一**允许存放真实（私有）面试数据的位置。

## 规则

- 本目录的内容（除 `.gitkeep` 和本 `README.md` 外）**已被 `.gitignore` 忽略**，不会被提交到仓库。
- 请把你的真实 JD / 简历 / 录音转写 / 分析结论**复制**（不要软链，避免泄漏绝对路径）到这里。
- 运行 skill 时，可以在这个目录下运行；skill 对工作目录无感，输出会写到当前目录的 `面试分析/`。

## 为什么是复制不是软链

软链会把真实数据的绝对路径带进仓库元数据，存在泄漏风险。复制则只搬内容、不带路径。

## 隐私

- 详见 [`../docs/privacy.md`](../docs/privacy.md)。
- 提交前建议跑一次 `bash ../scripts/check-pii.sh` 自查。
